本地会话的完整记录（包括 Claude 写过的每一个文件的全文）保存在那台电脑的 `%USERPROFILE%\.claude\projects\*\*.jsonl` 里。在那台电脑上运行：

```bash
python tools/export_local_claude_sessions.py --out session_exports
```

脚本会按关键词（PKD1 / STR / PGT-M / primer / CE / 引物 等）筛选会话，导出为可读的 Markdown，并把 Claude 用 Write 工具写过的文件**原样还原**到 `session_exports/<会话>/files/` 下。导出后放进本仓库，备份就完整了。

> 网页版 claude.ai 的普通聊天（非 Claude Code）无法通过工具读取。可以在 claude.ai → Settings → Privacy → **Export data** 导出整个账号的数据，再用上面同一个脚本的 `--claude-ai-export <conversations.json>` 参数筛选。
