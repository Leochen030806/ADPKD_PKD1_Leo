## 2. 为什么用 STR 连锁分析做 PGT-M

- 单个胚胎细胞里的 DNA 很少，直接测突变时容易发生等位基因脱扣（ADO）。所以 PGT-M 通常同时**追踪携带突变的单倍型**：在基因两侧选多态性 STR 标记，看胚胎遗传了哪条染色体。
- **两侧都要有标记**：5′ 上游（着丝粒侧，cen）和 3′ 下游（端粒侧，pter）各放几个。一侧发生重组时，另一侧仍然能给出信息。
- **离基因越近越好**：大约 1 cM ≈ 1 Mb。首选 1 Mb 以内的标记，需要补信息量时才放宽到约 1.5 Mb。
- **信息量**：只有当对应的亲本在该位点是**杂合子**时，这个标记才有用。目标期望杂合度 He ≳ 0.7。
- **Motif 的选择**：四核苷酸重复的 stutter 最小、CE 峰最干净；三核苷酸次之；二核苷酸多态性最高，但 stutter 也最重；单核苷酸重复不用。
- **拷贝数下限（经验值）**：二核苷酸 ≥ 12，三核苷酸 ≥ 8，四核苷酸 ≥ 6。

## 3. 通用尾（universal tail）三引物体系

荧光引物不直接标记染料，而是在 5′ 端加一段**通用尾**，再由带染料的通用引物去结合这段尾。这样换颜色只需换尾巴，基因特异的锚定序列（anchor）不用动。

| 染料（通道） | 尾前缀 | 尾序列 5′→3′ | 长度 |
|---|---|---|---|
| FAM（蓝） | M41 | `GGTTTTCCCAGTCACGAC` | 18 |
| HEX（绿） | M20 | `GTAAAACGACGGCCAGTG` | 18 |
| NED（黄） | MCM | `CATGGTCATAGCTGTTTCCTG` | 21 |
| PET（红） | M-Pet | `CCGCTAATTCAACCCATTGC` | 20 |

- 另一条非荧光引物加 **pigtail `gttt`**（4 bp），作用是让产物统一加上 +A，避免 −A/+A 双峰。曾有一个标记（1299）为了凑准目标长度用过 2 bp 的 `gt`。
- **扩增子长度公式（任何时候都不能出错）**：`+tail 长度 = 裸长 + F 端尾长 + R 端尾长`。CE 上看到的是 +tail 长度，Primer3 里填的是裸长。
- 做 in-silico PCR、BLAST 或二聚体检查时，**只用 anchor**，先把尾巴去掉。
- 报告里的 Tm 是 **anchor 的 Tm**，不是带尾全长 oligo 的 Tm。

**来源**：`skills/pgtm-str-panel-order/references/universal_tails.md`

## 4. 颜色 × 长度网格（CE 通道平衡）

- 四个荧光通道 FAM / HEX / NED / PET 用于标记，第五个通道（LIZ）留给 size standard。
- 工作窗口约 **130–350 bp**；同一种颜色内片段不能重叠，间距目标约 20 bp。
- 每种颜色约 3 个标记，12-plex 正好排满。
- 允许 1 个长片段备份标记落在窗口外（PKD1 中是 PET 429 bp）。

## 8. STR 挖掘流程（平台干实验区，TRExplorer 版本 2.1）

PKD1 运行 `PKD1_20261021-121226` 的参数：
- 窗口：基因两侧各 ±1 Mb，即 `chr16:1,088,708-3,135,898`
- 漏斗：TRExplorer 窗口内共 4840 个位点 → 保留 motif 为 2–6 bp 的 2812 个 → 进入风险标记与分级
- 分级阈值：**A 级 He ≥ 0.70**；**B 级 He 0.60–0.70**，或带 VC / 需要 BLAST 的位点；C 级 He < 0.60；「排除」= VC 内 ≥ 5 个 TR，或 VC 外扩 ≥ 50 bp
- 可比对性（mappability）< 0.5 的位点标记为「需BLAST」，但不直接剔除
- SNP 轨道用 `snp151Common`；引物侧翼取 200 bp；同时标记节段重复区（segdup）
- 分级结果：A 6 个 / B 81 个 / C 2507 个 / 排除 218 个
- PKD2 也跑过一次：`PKD2_20261021-130345`
- 组会讲稿中统一的口径：**PKD1 共 31 个位点进入引物设计（其中 8 个以前做过），PKD2 共 37 个**；PKD1 最终入选 18 个

**来源**：`platform/panel_studio/runs/*.json`；组会讲稿会话（2026-10-27）

## 9. 引物设计与验证要点

- Primer3 参数：长度 18–24 nt，Tm 58–62 °C（最优 60 °C，F/R 相差 ≤ 1.5 °C），GC 40–60%，`PRIMER_MAX_POLY_X=4`，产物大小范围用**裸长**。模板见 `skills/pgtm-str-panel-design/assets/primer3_settings_template.txt`。
- 排除区：重复区本身、RepeatMasker 标出的 Alu/LINE、常见 SNP（尤其不能落在 3′ 端，否则会造成等位基因脱扣）。
- 验证分三步：
  1. UCSC In-Silico PCR：单一产物、位置正确、大小正确
  2. Primer-BLAST：**不能扩增假基因**（PKD1 必查）
  3. IDT OligoAnalyzer：发夹结构 Tm 低于退火温度；自身二聚体和异源二聚体 ΔG 不低于约 −9 kcal/mol；多重体系要做全部引物两两之间的交叉二聚体矩阵
- 从没用过、改过颜色或位置的标记，进入多重体系之前必须先做**单重 PCR** 验证。

## 10. 湿实验常规参数

| 项目 | 参数 |
|---|---|
| 胶图（滴定）| 1% 琼脂糖 / 1× TBE / 5.5 V/cm / 45 min；10 µL 产物 + 2 µL loading dye，上样 10 µL |
| 温度梯度 | 常用 55 / 60 / 65 °C，每个温度：2 个 gDNA（如 NA11518、NA06075，5 ng/µL）+ 1 个 NTC（HPLC 水） |
| 判读重点 | **NTC 是否干净**是能否进入多重体系的首要判据；其次看是否为单一特异条带、亮度随 Ta 的变化趋势 |
| EtBr | 120 mL TBE 中加 3 µL（10 mg/mL 储液，终浓度约 0.25 µg/mL），可以继续沿用 |
| GeneScan 500 LIZ（货号 4322682） | 每管 200 µL × 2 = 400 µL；按 0.5 µL/孔约可做 800 个反应（每管体积数据来自第三方，以纸质说明书为准） |
| Ladder 型号（待核对） | worksheet 上标注的 1000/750/500/250 这组条带，与 Takara DL2000 一致；1 kb Plus 里没有 250 和 750。平台暂时默认 DL2000 |
