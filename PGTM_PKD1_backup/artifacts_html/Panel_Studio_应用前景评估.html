一、市场背景与用户需求

1.1 PGT-M 市场规模

全球 PGT-M 市场现状
  • 年增长率： 12-15% (2020-2030)
  • 主要区域： 中国、欧洲、北美、日本、澳大利亚
  • 主要驱动： ADPKD、囊肿性纤维化、地中海贫血等高频单基因病
  • 中国特殊性： 生育政策、遗传病携带者筛查意愿高、成本敏感度高

1.2 你面向的用户群体

用户分类 数量规模 典型特征 需求强度
一级：大型生殖中心 中国 50-80 家 月 10-30 个 PGT-M 病例、多基因、高标准化要求 ⭐⭐⭐⭐⭐ 极高
二级：区域性实验室 中国 200-300 家 月 2-10 个病例、常见基因、成本敏感 ⭐⭐⭐⭐ 高
三级：医学遗传学研究所 全球 500+ 家 科研性质、低频基因、追求学术认可 ⭐⭐⭐ 中
四级：外包检测服务商 全球 100+ 家 白标需求、集成现有流程、国际扩展 ⭐⭐⭐⭐ 高

1.3 核心痛点（基于你的真实经历）

🔄 重复流程

每个新基因都要重新跑一遍 TRF → UCSC → Primer3 → BLAST 的完整流程，手工参数调整和记录

📊 数据追踪困难

多次 multiplex 组合尝试后难以回溯哪个组合失败、为什么失败、下一步应该怎么调整

📝 手工报告生成

从 GeneMapper 数据 → PowerPoint 幻灯片的转换是纯手工，容易出错且耗时

⚙️ 参数透明性

脚本是黑盒，修改参数后难以理解每个决策的影响，无法在 UI 中实时调整

二、你的竞争优势分析

2.1 技术优势 ⭐⭐⭐⭐⭐

✓ 核心技术亮点
  • 自动化深度： 从基因名到订单清单的全流程自动化（业界少见）
  • 参数透明化： 每个步骤的参数都可编辑、可追踪、可重现
  • Gel 校准算法： 子像素级自动检测 + 手工微调的混合方案（业界先进）
  • 多标记生命周期管理： 从 STR candidate → primer_design → order_item 的三层状态机
  • Multiplex 记忆： 自动追踪每次组合的结果，指导下一步尝试

2.2 用户价值优势 ⭐⭐⭐⭐⭐

✓ 为什么用户会付费
  • 时间节省： 新基因设计从 2-3 周 → 3-5 天（70-80% 时间节省）
  • 成本降低： 减少失败实验的成本（不再盲目尝试 multiplex）
  • 质量提升： 参数标准化、可重现、可审计
  • 知识积累： 平台记忆所有尝试，成为实验室的"智能顾问"
  • 合规能力： 完整的审计日志（重要的临床应用）

2.3 学术与商业结合的优势 ⭐⭐⭐⭐

✓ 学术背景的商业价值
  • 论文发表能力： PKD1 的成功案例可以发表，提升品牌
  • 学术认可： 学者倾向于采用有论文支撑的工具
  • 定制化需求理解： 你是领域内人，理解每个实验室的差异性需求
  • 连续迭代能力： 可以持续添加新基因、新功能

三、现实挑战与风险

3.1 市场规模限制 ⚠️

潜在用户总数估计
  • 中国一级用户： 50-80 家 × ¥5000-10000/年 = ¥250-800 万/年
  • 中国二级用户： 200-300 家 × ¥2000-3000/年 = ¥400-900 万/年
  • 国际用户： 200-300 家（发达国家、日本）× ¥3000-5000/年 = ¥600-1500 万/年
  • 理论上限： ¥1.25-3.2 亿/年（但实际成交率只有 5-15%）
  • 现实可达目标： 第 1-2 年 ¥200-500 万，第 3-5 年 ¥1000-3000 万

3.2 供应链依赖 ⚠️

关键风险
  • UCSC 数据库： 依赖外部免费资源，可能变收费或服务中断
  • Primer3： 开源项目，需要保持兼容性
  • GeneMapper 数据： 用户端的专有软件，版本更新可能破坏兼容性
  • 应对方案： 需要内化 UCSC 数据、支持多版本 GeneMapper、建立兼容性测试框架

3.3 法规与合规风险 ⚠️

法规考虑
  • 如果涉及临床应用： 可能被视为医疗器械，需要注册（中国 NMPA）
  • 隐私合规： 大量遗传数据存储需符合 GDPR、HIPAA 等
  • 跨境数据流： 数据本地化需求（特别是中国）
  • 建议策略：
    • 定位为"科研工具"而非"临床诊断工具"（避免监管）
    • 强调数据所有权在用户（自托管选项）
    • 明确免责条款

3.4 竞争风险 ⚠️

潜在竞争对手
  • 大型 NGS 公司： Illumina, BGI, 华大基因等可能内置类似功能
  • 学术研究小组： 其他实验室可能开发类似工具并免费分享
  • 实验室自研： 大型中心自己开发内部系统（特别是一级用户）
  • 差异化防守：
    • 持续新增基因库（建立竞争壁垒）
    • 发表论文、建立学术影响力
    • 提供额外服务（咨询、培训、定制开发）

3.5 技术与运维风险 ⚠️

技术层面的挑战
  • 版本兼容性： hg38 更新到 hg39+ 时如何迁移
  • GeneMapper 多版本支持： 用户可能用不同版本的软件
  • UCSC 调用稳定性： 网络依赖、速率限制
  • 运维人力： 技术支持、数据库维护、用户问题处理

四、核心机会点 🎯

4.1 在细分领域建立垄断地位

PGT-M Panel Design 工具目前是空白市场
  • 没有专业商业软件专门做这个（大多是脚本 + 手工）
  • 如果你先上线 + 获得 20-30 家用户，竞争对手后来者劣势很大
  • 用户迁移成本高（已有数据、工作流习惯）

4.2 学术 + 商业的双重价值

独特的组合
  • 发表论文 → 提升学术地位 + 增强产品信誉
  • 学术案例库 → 成为教科书级的参考 → 新用户认识的途径
  • 可以同时申报基金（国自然、创新创业基金等）来补贴开发成本

4.3 地理优势 — 中国市场

中国特殊优势
  • 生育政策 + 遗传病筛查意愿 → PGT-M 需求高
  • 你本地 + 自托管基础设施 → 速度快、合规易
  • 语言优势 → 市场理解、用户沟通、本地化
  • 成本优势 → 中国用户愿意为本土工具付费（vs 国际付费软件）

4.4 国际扩展的杠杆点

国际市场的进入策略
  • 第 1-2 年： 专注中国（快速获得 30-50 个付费用户）
  • 第 2-3 年： 发表国际论文，参加学术会议
  • 第 3-5 年： 扩展到日本、澳大利亚、东南亚（这些国家的生殖遗传学很发达）
  • 第 5 年+： 欧美（更强的法规挑战但市场大）

七、最终评估与建议 ✅

💡 总体评价：高度可行，值得投入

这不是一个"百亿级机会"，但是一个稳健、有现金流、有学术价值的商业机会。

7.1 为什么值得做

  • 市场空白： 没有专业竞争对手，现在进入是最佳时机
  • 用户需求验证： 你自己就是用户，需求已验证，不是假想
  • 技术成熟度高： Demo 已经完成，核心算法已验证
  • 现金流潜力： 第 1 年就有可能实现小规模正现金流
  • 学术价值： 发表论文 + 商业化，双重收益
  • 低风险： 失败成本低（不需要大融资），成功概率相对高
